# 🎓 Project 01: Student Information Manager

> Create a custom type-aliased student record system and print formatted ID cards via pass-by-value functions.

---

## 📌 Short Description

Define a structure type alias using `typedef struct { char name[50]; int roll; float cgpa; } student;`. Prompt the user to input student attributes. Pass the structure object by value to a function `void printCard(student s)` that neatly displays the student ID card.

---

- [x] Pass-by-Value Function Display Utilities
