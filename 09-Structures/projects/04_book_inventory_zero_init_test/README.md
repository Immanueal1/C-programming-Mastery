# 📖 Project 04: Book Inventory Zero-Init Test

> Test zero-initialization semantics `{0}` on structures and update values using the dot operator.

---

## 📌 Short Description

Define a `Book` structure with `pages` (int) and `price` (float). Initialize `Book b1 = {0};`. Print its pages and price to verify they are `0` and `0.0`. Next, update the members using the Dot Operator (`b1.pages = 300`, `b1.price = 15.99`) and reprint the updated values.
