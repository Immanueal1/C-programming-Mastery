# 💼 Project 02: Employee Roster (Array of Structures)

> Manage multiple employee records inside an Array of Structures and find the top earner.

---

## 📌 Short Description

Create an array of 3 `Employee` structures containing `id` (int) and `salary` (float). Use a `for` loop to prompt for and read data into `emp[i].id` and `emp[i].salary`. Use a second loop to search the array, locate the highest salary, and print the corresponding employee ID.

---

## 📚 Topics Covered

- [x] Array of Structures Allocation (`Employee emp[3]`)
- [x] Looped Array Member Access (`emp[i].salary`)
- [x] Maximum Search Logic across Structure Records

---

## 🎯 Learning Objectives

- Store and process multiple heterogeneous records in Arrays of Structures.
- Implement search logic comparing structure member values.
