# 🎓 Project 03: Student Grades Tracker

> Manage student mark records using a 2D array and calculate individual student average scores via row-wise processing.

---

## 📌 Short Description

Create a 2D array `marks[3][4]` representing 3 students and 4 academic subjects. Prompt the user for input. Write a function `printStudentAverages(int marks[][4], int students)` that iterates through each student row, sums their 4 subject marks, calculates their average, and prints the results.

---

## 📚 Topics Covered

- [x] 2D Array Real-World Modeling (`marks[students][subjects]`)
- [x] Passing 2D Arrays to Functions (`int mat[][4]`)
- [x] Row-Wise Accumulator Processing

---

## 🎯 Learning Objectives

- Structure real-world tabular data using 2D arrays.
- Implement row-wise processing logic inside functions receiving 2D parameters.
