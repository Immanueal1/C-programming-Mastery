# 📊 Project 01: Array Statistics Calculator

> Analyze a numeric dataset by implementing modular calculation functions for sum, average, maximum, and minimum values.

---

## 📌 Short Description

Write a program that prompts the user to enter 10 integers into an array. Pass the array and its size to four dedicated modular functions: `getSum()`, `getAverage()`, `getMax()`, and `getMin()`. Display the calculated statistical summary in `main()`.

---

## 📚 Topics Covered

- [x] Passing 1D Arrays to Functions (`void f(int arr[], int n)`)
- [x] Array Traversal & Accumulator Logic
- [x] Type Casting for Floating-Point Average Computation
- [x] Min/Max Search Algorithms

---

## 🎯 Learning Objectives

- Structure modular functions that process array parameters safely.
- Compute dataset statistics efficiently using single-pass loops.
