# ➕ Project 02: Matrix Addition Utility

> Perform element-wise mathematical addition on two 2x2 matrices and format the resultant matrix in a clean grid.

---

## 📌 Short Description

Declare two 2x2 integer matrices `mat1[2][2]` and `mat2[2][2]`. Prompt the user to input values for both matrices. Declare a third matrix `res[2][2]` and compute `res[i][j] = mat1[i][j] + mat2[i][j]` using nested `for` loops. Print the result matrix back to the console formatted as a grid.

---

## 📚 Topics Covered

- [x] 2D Array Declaration & Input Scanning
- [x] Nested `for` Loops for Row/Column Traversal
- [x] Element-Wise Matrix Mathematics
- [x] Grid Console Output Formatting (`printf("\n")`)

---

## 🎯 Learning Objectives

- Manipulate multi-dimensional grid structures using nested loops.
- Compute matrix sums and maintain row-major formatting on output.
