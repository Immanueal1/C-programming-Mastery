# 💡 Chapter 2: Interview Preparation

> Technical interview questions, conceptual theory, debugging snippets, output prediction exercises, and multiple-choice questions focusing on Chapter 2: Instructions & Operators.

---

## 📌 Short Description

This module provides targeted technical interview preparation materials covering instructions, LHS assignment rules, operator precedence, associativity, implicit type promotion vs explicit casting, Bitwise XOR vs exponentiation, negative modulo arithmetic, and truthiness evaluation rules in C.

---

## 📚 Topics Covered

- [x] Three Main Types of Instructions (Type Declaration, Arithmetic, Control)
- [x] Left Hand Side (LHS) Assignment Rules (`a + b = c;` Failure Analysis)
- [x] Operator Precedence and Evaluation Hierarchy
- [x] Operator Associativity (Left-to-Right vs Right-to-Left Rules)
- [x] Implicit Type Conversion (`int` / `float`) & Automatic Promotion
- [x] Explicit Type Casting `(type)` Syntax & Truncation Mechanics
- [x] Bitwise XOR (`^`) vs Exponentiation (`pow()`)
- [x] Modulo Operator (`%`) Behavior with Negative Numerators & Denominators
- [x] Boolean Truthiness (Non-Zero is True, Zero is False)
- [x] Equality Comparison (`==`) vs Assignment (`=`) Traps

---

## 🎯 Learning Objectives

- Explain operator precedence and associativity rules to technical interviewers.
- Identify LHS assignment errors and illegal variable expressions.
- Predict output values for multi-operator expressions relying on natural associativity.
- Differentiate between bitwise AND (`&`) and logical AND (`&&`) truth evaluations.
- Solve conceptual MCQs testing type conversion, casting, and modulo arithmetic.
