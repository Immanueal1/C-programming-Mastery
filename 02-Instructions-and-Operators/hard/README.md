# 🔴 Chapter 2: Hard Practice Problems

> Advanced C programming challenges focusing on float scaling, digit extraction, kinematics equations, date decoding, bitwise vs logical operations, and XOR swapping algorithms.

---

## 📌 Section Overview

This directory contains 10 advanced problems designed to push arithmetic and logical expression engineering to professional levels without using loops or conditional statements.

---

## 🎯 Learning Objectives

- Scale analog sensor values to physical voltage ranges using float calculations.
- Reverse multi-digit integers and extract packed dates (`DDMMYYYY`) mathematically.
- Implement physics formulas using `sqrt()` and `pow()` from `<math.h>`.
- Differentiate between Bitwise AND (`&`) and Logical AND (`&&`).
- Apply the hardware-efficient XOR swapping algorithm (`A = A ^ B`).
