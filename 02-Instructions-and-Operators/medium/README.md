# 🟡 Chapter 2: Medium Practice Problems

> Intermediate C programming challenges focusing on float math formulas, relational combinations, left-to-right associativity, leap year logic, and variable swaps.

---

## 📌 Section Overview

This directory contains 10 intermediate problems designed to strengthen logical thinking, expression parsing, precedence handling, and mathematical conversions in C without using conditional statements or loops.

---

## 🎯 Learning Objectives

- Apply BODMAS and grouping parentheses in electrical and geometric formulas.
- Evaluate complex boolean expressions combining relational and logical AND/OR (`&&`, `||`).
- Observe left-to-right associativity for operators of equal precedence (`*` and `/`).
- Handle implicit vs explicit casting during percentage calculations (`(float)current / goal`).
- Use modulo and division for time formatting and arithmetic swaps.
