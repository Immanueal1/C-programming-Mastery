# 🧾 Project 05: Basic GST & Split Bill Generator

> A restaurant bill calculator applying 5% CGST + 5% SGST, splitting cost among friends, and rounding mathematically to nearest integer.

---

## 📌 Short Description

Read a total restaurant bill amount and the number of friends splitting it. Add 5% CGST and 5% SGST to the total bill. Calculate the exact float amount each friend must pay, and then round it mathematically to the nearest integer (`(int)(per_person + 0.5)`) for easy cash payment.

---

## 📚 Topics Covered

- [x] Tax Surcharge Calculations (CGST & SGST Addition)
- [x] Equal Bill Splitting Arithmetic
- [x] Non-Conditional Float Rounding `(int)(val + 0.5)`

---

## 🎯 Learning Objectives

- Apply tax percentages sequentially to commercial transactions.
- Implement mathematical rounding up/down to nearest integer without `if` or `ceil()`.
