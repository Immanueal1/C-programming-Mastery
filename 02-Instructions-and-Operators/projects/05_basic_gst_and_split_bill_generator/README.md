# 🧾 Project 05: Basic GST & Split Bill Generator

## Description
Read a total restaurant bill amount and the number of friends splitting it. Add 5% CGST and 5% SGST to the total. Calculate the exact float amount each friend must pay, and then round it mathematically to the nearest integer for easy cash payment.

## Concepts Used
- Percentage arithmetic (`bill * 0.05`)
- Float division (`total / friends`)
- Explicit type casting `(int)(amount + 0.5)` for rounding
- Formatted bill printing
