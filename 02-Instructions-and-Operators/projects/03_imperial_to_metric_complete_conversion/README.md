# 📏 Project 03: Imperial to Metric Complete Conversion

> A unit conversion tool transforming distances in miles to kilometers, meters, and centimeters with aligned formatting.

---

## 📌 Short Description

Read a distance in Miles as a float. Convert and print the equivalent distance in Kilometers ($1\text{ mile} = 1.60934\text{ km}$), Meters, and Centimeters. Format the output in a clean, neatly aligned tabular structure using width specifiers.

---
