# 📏 Project 03: Imperial to Metric Complete Conversion

## Description
Read a distance in Miles. Convert and print it in Kilometers, Meters, and Centimeters, neatly aligned using width format specifiers.

## Concepts Used
- Multi-unit conversion multiplication
- Width format specifiers (`%10.2f`)
- Floating-point calculations
- Aligned terminal output
