# 📊 Project 02: TCS Aptitude Score Predictor

> A placement screening calculator computing weighted aptitude scores and boolean eligibility flags.

---

## 📌 Short Description

Read raw test scores for Quants, Logic, and Verbal reasoning. Apply corporate weights: 50% Quants, 30% Logic, 20% Verbal. Output the final weighted float score. Print `1` if the final score is $\ge 80.0$, and `0` otherwise without using `if` statements.

---

## 📚 Topics Covered

- [x] Weighted Floating-Point Arithmetic Calculations
- [x] Boolean Eligibility Expression Evaluation (`score >= 80.0`)
- [x] Precision Formatting for Percentage Scores

---

## 🎯 Learning Objectives

- Calculate weighted averages across multiple score components.
- Output pure Boolean pass/fail flags (`1` or `0`) using relational operators.
