# 📊 Project 02: TCS Aptitude Score Predictor

## Description
Read raw scores for Quants, Logic, and Verbal. Apply weights: 50% Quants, 30% Logic, 20% Verbal. Output the final weighted float score. Print 1 if the score is $\ge 80.0$, and 0 otherwise.

## Concepts Used
- Weighted percentage arithmetic
- Relational operators (`>=`)
- Floating-point precision
- Direct boolean output
