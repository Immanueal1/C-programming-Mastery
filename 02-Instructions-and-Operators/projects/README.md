# 🛠️ Chapter 2 Portfolio Mini Projects

> Practical, real-world mini projects built entirely using Chapter 2 concepts: sequential instructions, arithmetic formulas, precedence, relational/logical checks, and expressions without `if-else` or loops.

---

## 📌 Projects Overview

| Project Directory | Title | Core Objective |
| :--- | :--- | :--- |
| [`01_electronics_workbench_calculator/`](./01_electronics_workbench_calculator/) | Electronics Workbench Calculator | Read Voltage ($V$) and Resistance ($R$), calculate Current ($I = V/R$) and Power ($P = V^2/R$) using `<math.h>`. |
| [`02_tcs_aptitude_score_predictor/`](./02_tcs_aptitude_score_predictor/) | TCS Aptitude Score Predictor | Read raw scores, apply weights (50% Quants, 30% Logic, 20% Verbal), and print boolean eligibility ($\ge 80.0$). |
| [`03_imperial_to_metric_complete_conversion/`](./03_imperial_to_metric_complete_conversion/) | Imperial to Metric Complete Conversion | Read distance in Miles, convert and print in Kilometers, Meters, and Centimeters aligned using width specifiers. |
| [`04_the_5_digit_cryptography_shifter/`](./04_the_5_digit_cryptography_shifter/) | The 5-Digit Cryptography Shifter | Extract individual digits mathematically, shift by 1 with modulo 10 wrap-around, and output encrypted number. |
| [`05_basic_gst_and_split_bill_generator/`](./05_basic_gst_and_split_bill_generator/) | Basic GST & Split Bill Generator | Read bill amount & number of friends, apply 5% CGST + 5% SGST, calculate per-head float cost, and round to nearest integer. |

---

## 🎯 Implementation Rules

- Do NOT use conditional statements (`if`/`else`), loops (`while`/`for`), or custom functions beyond `main()`.
- Use arithmetic expressions, type casting, and logical expressions directly inside `printf()` or variables.
- Ensure all source code resides in `main.c` within each project folder.
