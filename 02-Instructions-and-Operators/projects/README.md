# 🛠️ Chapter 2: Portfolio Mini Projects

> Practical, real-world mini projects built entirely using Chapter 2 concepts: sequential instructions, mathematical calculations, logical expressions, and formula conversions. No `if-else` or loops!

---

## 📌 Short Description

This folder contains 5 hands-on portfolio mini projects designed to apply sequential calculations, physics & electrical formulas, weighted aptitude scoring, unit conversions, and digit cryptography using pure arithmetic and logical expressions.

---

## 📚 Topics Covered

- [x] Electrical Current & Power Dissipation Calculations (`01_electronics_workbench_calculator`)
- [x] TCS Aptitude Weighted Score Prediction & Boolean Cutoff Check (`02_tcs_aptitude_score_predictor`)
- [x] Imperial to Metric Distance Unit Conversion & Alignment Formatting (`03_imperial_to_metric_complete_conversion`)
- [x] 5-Digit Cryptography Mathematical Digit Shifter (`04_the_5_digit_cryptography_shifter`)
- [x] Restaurant GST Tax & Friend Bill Splitter with Integer Rounding (`05_basic_gst_and_split_bill_generator`)

---

## 🎯 Learning Objectives

- Translate multi-variable real-world formulas into C expressions cleanly.
- Calculate weighted floating-point averages and output Boolean screening pass/fail flags.
- Apply width format specifiers for aligned tabular console outputs.
- Extract, manipulate, and recombine individual digits mathematically without loops or strings.
- Calculate tax additions and perform mathematical rounding without conditional statements.
