# 🟢 Chapter 2: Easy Practice Problems

> Beginner-friendly C programming challenges focusing on arithmetic operations, integer division, modulo rules, type conversion, relational checks, and operator precedence.

---

## 📌 Section Overview

This directory contains 10 foundational problems designed to build confidence with integer math, type promotion rules, bitwise XOR vs `pow()`, explicit float truncation, and precedence syntax.

---

## 🎯 Learning Objectives

- Use integer division `/` and remainder `%` effectively.
- Understand C's `1` (True) and `0` (False) boolean evaluation without `if-else`.
- Observe implicit type promotion rules (e.g., `int / float` ➜ `float`).
- Avoid common traps like `^` vs `pow()` and the LHS assignment rule.
- Use explicit typecasting `(int)` and shorthand assignment operators (`+=`).
