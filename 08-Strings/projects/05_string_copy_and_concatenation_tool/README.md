# ✍️ Project 05: String Copy and Concatenation Tool

> Chain multiple string library operations sequentially to construct formatted output sentences.

---

## 📌 Short Description

Declare an empty destination buffer `greeting[100]`. Use `strcpy()` to copy `"Dear "` into `greeting`. Prompt the user to input their name. Concatenate the name onto `greeting` using `strcat()`. Next, concatenate `", Welcome!"` onto `greeting`. Print the complete formatted sentence.

---

## 📚 Topics Covered

- [x] Initializing Destination Buffers via `strcpy()`
- [x] Sequential Concatenation Chains via `strcat()`
- [x] Buffer Capacity Management

---

## 🎯 Learning Objectives

- Chain `<string.h>` operations sequentially to format output strings.
- Manage memory space during multi-step string additions.
