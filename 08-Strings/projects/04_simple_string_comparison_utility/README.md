# 📚 Project 04: Simple String Comparison Utility

> Build a dictionary-order checker using lexicographical string comparison functions.

---

## 📌 Short Description

Read two single-word strings from the user. Use `strcmp()` to compare them. If the return value is `0`, print `"They match!"`. If not, evaluate whether the return value is negative ($< 0$) or positive ($> 0$) and print which word would appear first in a dictionary.

---

## 📚 Topics Covered

- [x] Lexicographical String Comparison (`strcmp()`)
- [x] Evaluating Negative, Zero, and Positive Return Values
- [x] Dictionary Order Logic

---

## 🎯 Learning Objectives

- Apply `strcmp()` return values to determine alphabetical precedence.
- Avoid address comparison bugs (`str1 == str2`).
