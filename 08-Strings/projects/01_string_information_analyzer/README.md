# 📊 Project 01: String Information Analyzer

> Analyze a string input thoroughly by measuring visible character length, total array memory capacity, and individual boundary characters.

---

## 📌 Short Description

Write a program that prompts the user for a string using `fgets()`. Calculate and print its visible character length using `strlen()`, its total array allocation using `sizeof()`, and manually print its very first character (`str[0]`) and its last visible character (`str[strlen(str) - 1]`).

---

## 📚 Topics Covered

- [x] Multi-Word Line Input via `fgets()`
- [x] Visible Length Calculation (`strlen()`) vs Memory Allocation (`sizeof()`)
- [x] Boundary Character Index Access

---

## 🎯 Learning Objectives

- Inspect character array buffers and distinguish between active text length and byte capacity.
- Calculate character boundary indexes safely.
