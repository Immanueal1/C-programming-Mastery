# 👤 Project 02: Student Name & Input Utility

> Safely manage multi-word user input containing spaces using modern bounded string reading methods.

---

## 📌 Short Description

Create a program that prompts a student to enter their full name. First, demonstrate how `scanf("%s")` fails to read beyond spaces. Then, implement safe bounded input using `fgets(name, 50, stdin)` and display a personalized welcome message using `puts()`.

---

## 📚 Topics Covered

- [x] Demonstrating `scanf("%s")` Whitespace Cutoff
- [x] Safe Multi-Word Input with `fgets()`
- [x] String Output with `puts()`

---

## 🎯 Learning Objectives

- Understand stream reading limitations and apply safe `fgets()` input handlers.
- Handle user names containing spaces gracefully.
