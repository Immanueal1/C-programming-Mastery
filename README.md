## 🗺️ Learning Roadmap & Topics

1. **Basics & Variables**: Syntax, Data Types, Input/Output (`printf`, `scanf`), Variables, Constants.
2. **Instructions & Operators**: Arithmetic, Relational, Logical, Bitwise, Assignment, and Precedence.
3. **Conditional Statements**: `if`, `else-if`, `else`, `switch-case`, Ternary Operator.
4. **Loops**: `while`, `do-while`, `for` loops, Loop Control (`break`, `continue`).
5. **Functions & Recursion**: Function definitions, prototypes, Call by Value vs Reference, Recursion.
6. **Pointers**: Memory addresses, Pointer arithmetic, Pointers to Pointers, Function Pointers.
7. **Arrays**: 1D & 2D Arrays, Array manipulation, Passing arrays to functions.
8. **Strings**: Character arrays, String library functions (`string.h`), String manipulation.
9. **Structures & Unions**: `struct`, `union`, Nested structures, Typedefs.
10. **File I/O**: File operations (`fopen`, `fclose`, `fread`, `fwrite`, `fprintf`, `fscanf`).
11. **Dynamic Memory Allocation**: `malloc`, `calloc`, `realloc`, `free`, Memory leak prevention.
12. **Projects**: Hands-on projects categorized by difficulty (Beginner, Intermediate, Advanced).
13. **DSA Practice**: Fundamental Data Structures & Algorithms implemented in C.
14. **Interview Prep**: Questions, MCQs, output analysis, debugging challenges, and cheat sheets.
