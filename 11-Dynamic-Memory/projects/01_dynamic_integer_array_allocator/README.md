# 🔢 Project 01: Dynamic Integer Array Allocator

> Perform dynamic heap allocation for user-defined array sizes using `malloc()`.

---

## 📌 Short Description

Ask the user for an array size N. Use `malloc()` to allocate memory for N integers (`int *ptr = (int *) malloc(N * sizeof(int));`). Perform a safety check for `NULL`. Fill the memory with values, print them, and cleanly deallocate the memory using `free(ptr)`.

---

## 📚 Topics Covered

- [x] Dynamic Array Allocation (`malloc`)
- [x] Portable Size Calculation (`N * sizeof(int)`)
- [x] `NULL` Pointer Safety Checking
- [x] Deallocation via `free()`

---

## 🎯 Learning Objectives

- Request dynamic heap memory for user-specified array bounds.
- Apply `NULL` safety validation and deallocate heap memory responsibly.
