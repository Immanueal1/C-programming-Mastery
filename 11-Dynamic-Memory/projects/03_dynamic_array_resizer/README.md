# 📈 Project 03: Dynamic Array Resizer

> Expand dynamic memory capacity dynamically at run-time using `realloc()`.

---

## 📌 Short Description

Allocate 3 integers using `malloc()`. Later, prompt the user if they want to add 2 more slots. Use `realloc()` to expand the total capacity to 5 integers (`realloc(ptr, 5 * sizeof(int))`). Verify that old data is preserved, print the updated array, and free the memory.

---

## 📚 Topics Covered

- [x] Initial Heap Allocation (`malloc`)
- [x] Dynamic Block Expansion (`realloc`)
- [x] Data Preservation Verification

---

## 🎯 Learning Objectives

- Expand dynamic arrays seamlessly during program execution.
- Understand how `realloc()` preserves existing elements while appending new capacity.
