# 🎓 Project 02: Dynamic Student Marks Storage

> Allocate zero-initialized memory for student marks using `calloc()`.

---

## 📌 Short Description

Ask the user for N students. Use `calloc()` so all marks start strictly initialized at `0` (`calloc(N, sizeof(int))`). Check for `NULL`. Assign a few student marks, print the array, and free the heap memory.

---

## 📚 Topics Covered

- [x] Contiguous Allocation (`calloc`)
- [x] Zero-Initialization Verification
- [x] `NULL` Safety Guarding

---

## 🎯 Learning Objectives

- Use `calloc()` when initial element zeroing is required for data safety.
- Manage dynamic arrays for student record storage.
