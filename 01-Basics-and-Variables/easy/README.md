# 🟢 Chapter 1: Easy Practice Problems

> Beginner-friendly C programming challenges focusing on `printf()`, `scanf()`, primitive data types (`int`, `float`, `char`), constants, format specifiers, and basic math.

---

## 📌 Section Overview

This directory contains 10 foundational problems designed to build confidence with basic input/output operations, escape sequences, variable declarations, memory address operations (`&`), and output alignment.

---

## 🎯 Learning Objectives

- Print formatted single-line and multi-line strings using escape sequences.
- Read integer, float, and character values from standard input.
- Declare constants using `const` and `#define`.
- Control output precision and field width formatting.
