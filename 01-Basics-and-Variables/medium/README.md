# 🟡 Chapter 1: Medium Practice Problems

> Intermediate C programming challenges focusing on float math, formula calculations, variable swappers, typecasting, modulo arithmetic, and aligned columns.

---

## 📌 Section Overview

This directory contains 10 intermediate problems designed to strengthen mathematical problem-solving in C without using loops or conditional statements.

---

## 🎯 Learning Objectives

- Avoid integer division pitfalls (e.g., `9.0 / 5.0`).
- Apply basic geometry, financial math, and engineering formulas in C.
- Perform variable swaps using arithmetic operations.
- Utilize modulo (`%`) and division (`/`) operators for time conversions.
- Format multi-column decimal outputs with alignment specifiers (`%10.2f`).
