2. Attempt the output predictions in [`OUTPUT_PREDICTION.md`](./OUTPUT_PREDICTION.md) on paper before running the snippets in your C compiler.
3. Identify the errors in [`DEBUGGING.md`](./DEBUGGING.md) without using a compiler first to build strong visual code auditing skills.
4. Test your knowledge using the practice multiple-choice questions in [`MCQs.md`](./MCQs.md).
