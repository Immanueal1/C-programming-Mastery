# 🔴 Chapter 1: Hard Practice Problems

> Advanced C programming challenges focusing on deep digit extraction, truncation, typecasting, left-aligned table formatting (`%-15s`), `sizeof()` operator, and multi-input whitespace buffer handling.

---

## 📌 Section Overview

This directory contains 10 advanced problems designed to test low-level arithmetic manipulation, buffer handling, memory layout inspection, and production-style terminal output formatting without using control flow statements.

---

## 🎯 Learning Objectives

- Handle leftover newline character traps when reading character inputs after integers/floats (`scanf(" %c", ...)`).
- Perform digit extraction and mathematical reversal using modulo (`%`) and integer division (`/`).
- Split floating-point numbers into integer and fractional parts via explicit typecasting `(int)`.
- Use left-aligned specifiers (`%-15s`) for aligned table columns.
- Measure data type memory footprints using `sizeof()`.
