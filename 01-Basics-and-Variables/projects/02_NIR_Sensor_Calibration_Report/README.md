# 🔬 Project 02: NIR Microplastic Sensor Calibration Report

## Description
A script that prompts a hardware engineer for baseline wavelength, observed wavelength, and sample volume, calculates the wavelength deviation, and prints a cleanly formatted technical calibration report.

## Concepts Used
- Floating-point math & subtraction
- `printf` precision control (`%.2f`, `%.4f`)
- Multi-line console formatting
- Input parsing
