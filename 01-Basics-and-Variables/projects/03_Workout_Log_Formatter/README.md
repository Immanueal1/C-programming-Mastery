# 🏋️ Project 03: Powerbuilding Workout Log Formatter

## Description
Prompt the lifter for weight lifted (float), sets (int), and reps (int). Calculate the total workout volume ($\text{Weight} \times \text{Sets} \times \text{Reps}$) and print a summary table of the workout session using fixed-width format specifiers.

## Concepts Used
- Integer and float arithmetic multiplication
- Aligned text columns (`%12s`, `%8.2f`)
- Clean console table borders
- Format specifiers
