# 🎓 Project 05: Tutoring Academy Fee Receipt System

## Description
Read a student's ID (int), course fee (float), and late days (int). Apply a penalty of ₹50 per late day. Print an official payment slip calculating the final total amount due.

## Concepts Used
- Combined integer & floating-point arithmetic
- Input buffer handling
- Receipt layout formatting
- Dynamic fee additions
