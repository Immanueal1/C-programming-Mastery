# 🧾 Project 01: TCS Digital Candidate Profile Generator

## Description
Build a console-based application that prompts the user for candidate details (Initials, Age, CGPA, Aptitude Score) and prints a highly structured, boxed ASCII-art ID card.

## Concepts Used
- Multiple I/O (`printf`, `scanf`)
- Variable Declarations (`int`, `float`, `char`)
- Space/Buffer handling (`scanf(" %c", &var)`)
- Custom width formatting & ASCII borders
