# 🔌 Project 04: PCB Component Bill Estimator

## Description
Prompt the user for the quantity of 4 different hardware components. Calculate the subtotal, apply a hardcoded 18% GST using a `#define` or `const` variable, and generate an aligned, professional invoice receipt.

## Concepts Used
- `const` variables & `#define` preprocessor directives
- Sequential arithmetic operations
- Percentage calculations (`subtotal * 0.18`)
- Currency formatting (`%.2f`)
