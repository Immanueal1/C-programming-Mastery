# 🛠️ Chapter 1 Portfolio Mini Projects

> Practical, real-world portfolio mini projects built entirely using Chapter 1 concepts: variables, formatting, basic math, constants, and console I/O.

---

## 📌 Projects Overview

| Project Directory | Title | Core Objective |
| :--- | :--- | :--- |
| [`01_TCS_Digital_Candidate_Profile/`](./01_TCS_Digital_Candidate_Profile/) | TCS Digital Candidate Profile Generator | Input candidate details (Initials, Age, CGPA, Aptitude Score) and render a structured ASCII-art ID card. |
| [`02_NIR_Sensor_Calibration_Report/`](./02_NIR_Sensor_Calibration_Report/) | NIR Microplastic Sensor Calibration Report | Read baseline/observed wavelengths & volume, calculate deviation, and format a technical report. |
| [`03_Workout_Log_Formatter/`](./03_Workout_Log_Formatter/) | Powerbuilding Workout Log Formatter | Calculate total training volume ($\text{Weight} \times \text{Sets} \times \text{Reps}$) and render a summary table. |
| [`04_PCB_Component_Bill/`](./04_PCB_Component_Bill/) | PCB Component Bill Estimator | Calculate component quantities, apply 18% GST with constants, and generate an aligned invoice receipt. |
| [`05_Tutoring_Fee_Receipt/`](./05_Tutoring_Fee_Receipt/) | Tutoring Academy Fee Receipt System | Calculate late fee penalties ($\text{Late Days} \times ₹50$) and print an official tuition payment slip. |

---

## 🎯 Implementation Rules

- Do NOT use conditional statements (`if`/`else`), loops (`while`/`for`), or functions beyond `main()`.
- Use fixed-width format specifiers (`%15s`, `%10.2f`) for clean console visual alignment.
- Ensure all source code resides in `main.c` within each project folder.
