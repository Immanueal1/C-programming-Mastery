# ❓ Top 10 Technical Interview Theory Questions

> Core technical interview questions covering code reusability, function prototypes, library vs. custom functions, arguments vs. parameters, pass-by-value mechanics, single return rules, recursion properties, stack overflow crashes, and iterative vs. recursive algorithm trade-offs.

---

### Question 1
Explain the principle of "Code Reusability" and how functions help achieve it.

---

### Question 2
What is a function prototype, and why does the compiler require it if the function is defined below `main()`?

---

### Question 3
Differentiate between Library Functions and User-Defined Functions. Provide an example of each.

---

### Question 4
Explain the difference between an Argument (Actual Parameter) and a Parameter (Formal Parameter).

---

### Question 5
Define "Pass-by-Value" in C. Why doesn't modifying a parameter inside a function alter the original variable in `main()`?

---

### Question 6
State the "Single Return Value Rule" for C functions. Can a function return two integers simultaneously?

---

### Question 7
What is Recursion? Explain the mathematical analogy of recursion using a simple formula.

---

### Question 8
Every recursive function must have a "Base Case" and a "Recursive Step". Define both.

---

### Question 9
What happens in system memory if a recursive function is missing its base case? Explain the term "Stack Overflow".

---

### Question 10
Is it true that anything that can be written using an iterative loop can also be written using recursion? Why might recursion be preferred in some complex algorithms?
