# 🛠️ Chapter 5: Portfolio Mini Projects

> Practical, real-world mini projects built entirely using Chapter 5 concepts: Functions, Pass-by-Value, Return Values, and Recursion. No arrays or pointers!

---

## 📌 Short Description

This folder contains 5 hands-on portfolio mini projects designed to apply modular arithmetic functions, multi-stage student grade calculators, salary tax/bonus calculators, math utility suites, and recursive sequence tools.

---

## 📚 Topics Covered

- [x] Menu-Driven Four-Function Arithmetic Engine (`01_modular_calculator`)
- [x] Multi-Stage Student Grade Calculation Pipeline (`02_student_marks_calculator`)
- [x] Takes-Home Salary Calculation System (`03_simple_salary_calculator`)
- [x] Mathematical Utility Functions Suite (`04_mathematical_utility_program`)
- [x] Recursive Natural Sum & Factorial Engine (`05_recursive_number_utility`)

---

## 🎯 Learning Objectives

- Structure multi-function C programs driven by an interactive `main()` menu.
- Chain function calls where the return value of one function feeds into another.
- Separate business calculations (tax, bonus, percentage) into dedicated, testable functions.
- Build clean, formatted reports in `main()` using modular function outputs.
- Construct recursive algorithms for natural sums and factorials.
