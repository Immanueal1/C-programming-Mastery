# 💵 Project 03: Simple Salary Calculator

> A financial payslip generator calculating tax deductions and bonus additions to determine net take-home salary.

---

## 📌 Short Description

Create a function `calculateTax(float salary)` that returns the tax amount (10% of salary). Create `calculateBonus(float salary)` that returns the bonus (5%). In `main()`, read the base salary, calculate the final take-home salary using these functions, and display a payslip.

---

## 📚 Topics Covered

- [x] Financial Percentage Calculations in Functions
- [x] Pass-by-Value Floating Point Arguments
- [x] Formatted Console Payslip Generation

---

## 🎯 Learning Objectives

- Modularize financial business rules into clear, independent functions.
- Combine base salary, tax deductions, and bonus additions inside `main()`.
