# 🔄 Project 05: Recursive Number Utility

> A mathematical analysis utility computing natural sums ($\sum N$) and factorials ($N!$) recursively.

---

## 📌 Short Description

Write a program featuring two recursive functions: `recursiveSum(n)` and `recursiveFactorial(n)`. Ask the user for a number N and use these functions to display the sum of numbers up to N, and the factorial of N.

---

## 📚 Topics Covered

- [x] Recursive Natural Sum ($\text{sum}(n) = n + \text{sum}(n - 1)$)
- [x] Recursive Factorial ($\text{fact}(n) = n \times \text{fact}(n - 1)$)
- [x] Base Case Safety Constraints

---

## 🎯 Learning Objectives

- Implement recursive mathematical formulas cleanly.
- Verify base case stopping conditions to prevent stack overflow crashes.
