# 🔢 Project 01: Modular Calculator

> A four-operation arithmetic program using dedicated user-defined functions for addition, subtraction, multiplication, and division.

---

## 📌 Short Description

Write a program with `main()` as the menu. Create four separate user-defined functions: `add()`, `subtract()`, `multiply()`, and `divide()`. Take two inputs from the user, call the appropriate function, and print the returned result in `main()`.

---

## 📚 Topics Covered

- [x] Dedicated Arithmetic Functions
- [x] Return Values (`int` and `float`)
- [x] Interactive Terminal Input Handling

---

## 🎯 Learning Objectives

- Break arithmetic operations into single-purpose modular functions.
- Pass arguments and capture return values cleanly in `main()`.
