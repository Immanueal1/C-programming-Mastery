# 📐 Project 04: Mathematical Utility Program

> A math utility suite computing squares, cubes, and even/odd parity for any user-provided integer.

---

## 📌 Short Description

Build a math library program. Write functions for `findSquare()`, `findCube()`, and `isEven()`. Prompt the user for a number, pass it to all three functions, and neatly format the returned results.

---

## 📚 Topics Covered

- [x] Utility Functions Suite Design
- [x] Integer Exponentiation (`n * n`, `n * n * n`)
- [x] Boolean Parity Check Functions

---

## 🎯 Learning Objectives

- Build a general-purpose math utility suite.
- Re-use functions across multiple prompt iterations.
