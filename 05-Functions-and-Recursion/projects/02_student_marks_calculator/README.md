# 🎓 Project 02: Student Marks Calculator

> A multi-stage student grading pipeline computing subject percentages and Pass/Fail status.

---

## 📌 Short Description

Create a function `calculatePercentage(int p, int c, int m)` that returns the `float` percentage for Physics, Chemistry, and Math. Create another function `printGrade(float percentage)` that outputs "Pass" or "Fail". Call them sequentially from `main()`.

---

## 📚 Topics Covered

- [x] Multi-Parameter Input Processing
- [x] Floating-Point Return Values
- [x] Sequential Function Pipeline Chaining

---

## 🎯 Learning Objectives

- Pass multiple subject marks to a calculation function.
- Feed the output of one function into another decision-making function.
