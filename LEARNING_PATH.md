# 🎓 C Programming Mastery Learning Path

> A step-by-step study guide designed for computer science students, self-taught programmers, and job seekers to master procedural software development.

---

## 📌 Recommended Study Sequence

To build a bulletproof foundation in low-level systems programming, follow this 4-step chapter methodology:

```text
Step 1: Read Theory & Visual Cheat Sheet  ➜  Step 2: Solve Graduated Practice (Easy ➜ Med ➜ Hard)
                                                                 ↓
Step 4: Build Portfolio Mini Project      ⇦  Step 3: Test Technical Interview Questions
```

---

## 🗺️ Step-by-Step Curriculum

### Tier 1: Core Fundamentals
1. **01-Basics-and-Variables**: Compiler setup, `printf`, `scanf`, primitive types (`int`, `float`, `char`), constants, format specifiers.
2. **02-Instructions-and-Operators**: Arithmetic, relational, logical, bitwise operators, precedence rules.
3. **03-Conditional-Statements**: Decision-making using `if`, `if-else`, nested conditionals, `switch-case`, ternary operator.
4. **04-Loops**: Iteration constructs (`while`, `do-while`, `for`), loop control (`break`, `continue`).

### Tier 2: Modularization & Memory Mechanics
5. **05-Functions-and-Recursion**: Function prototypes, pass-by-value vs pass-by-reference, call stack execution, recursion.
6. **06-Pointers**: Memory addresses, dereferencing (`*`), address-of (`&`), pointer arithmetic, pointers-to-pointers.
7. **07-Arrays**: 1D & 2D array memory layouts, passing arrays to functions, matrix manipulation.
8. **08-Strings**: Character buffers, string handling without standard libraries, `<string.h>` utilities (`strlen`, `strcpy`, `strcmp`).

### Tier 3: Advanced Systems & Memory Management
9. **09-Structures**: User-defined data types, `struct`, `union`, nested structures, `typedef`.
10. **10-File-IO**: File stream pointers (`FILE*`), reading/writing text & binary files (`fopen`, `fread`, `fwrite`, `fprintf`).
11. **11-Dynamic-Memory**: Heap allocation using `malloc()`, `calloc()`, `realloc()`, memory deallocation via `free()`, preventing memory leaks.

### Tier 4: Software Portfolio & Placement Readiness
12. **12-Projects**: 60 Real-World Practical Projects across 3 Tiers (20 Easy, 20 Medium, 20 Advanced including 5 Specialized Capstones and 1 Flagship Systems Controller).
13. **13-DSA-Practice**: Low-level implementations of Singly/Doubly Linked Lists, Stacks, Queues, Binary Trees, Graphs, Sorting algorithms.
14. **14-Interview-Prep**: TCS Digital & tech interview preparation (output prediction, debugging challenges, pointer puzzles, MCQs).

## 💻 Recommended Developer Setup

### Linux / macOS
```bash
# Install GCC compiler
sudo apt update && sudo apt install build-essential gcc

# Verification
gcc --version
```

### Windows
1. Download & Install [MinGW-w64](https://www.mingw-w64.org/).
2. Add `C:\mingw64\bin` to your System Environment Variables (`PATH`).
3. Verify in Command Prompt:
   ```cmd
   gcc --version
   ```
