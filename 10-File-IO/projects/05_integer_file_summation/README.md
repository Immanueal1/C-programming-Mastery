# ➕ Project 05: Integer File Summation

> Read multiple integer records from a file using `fscanf()`, perform calculations, and display the result.

---

## 📌 Short Description

Assume a file `numbers.txt` contains three space-separated integers (e.g., `10 20 30`). Open the file in `"r"` mode, use `fscanf()` three times to load the numbers into RAM variables, calculate their total sum (`sum = n1 + n2 + n3`), display the result on the console screen, and cleanly close the file.
