# 📜 Project 04: The Log Appender Utility

> Append execution data to a log file without deleting existing history using `"a"` mode.

---

## 📌 Short Description

Prompt the user for their age. Open `history.txt` in `"a"` (append) mode. Write the formatted age record to the file on a new line (`fprintf(fptr, "Age: %d\n", age)`). Close the file. Demonstrate that running the program multiple times preserves all historical entries.

---

## 📚 Topics Covered

- [x] Append Mode (`"a"`)
- [x] Preserving Existing File Contents
- [x] Newline Formatting (`\n`) in Log Entries

---

## 🎯 Learning Objectives

- Build persistent history logging utilities using `"a"` mode.
- Verify that old file records remain untouched when appending.
