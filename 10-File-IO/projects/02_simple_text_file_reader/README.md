# 📖 Project 02: Simple Text File Reader

> Open, validate, and display file contents character-by-character using an EOF loop.

---

## 📌 Short Description

Open a text file `story.txt` in `"r"` mode. Implement a `NULL` pointer check (`if (fptr == NULL)`). If the file exists, execute the standard infinite `while(1)` EOF loop with `fgetc()` to print the story to the console screen. Close the file cleanly.

---

## 📚 Topics Covered

- [x] Read Access Mode (`"r"`)
- [x] `NULL` Pointer Safety Guarding
- [x] Character Reading via `fgetc()`
- [x] Infinite `while(1)` EOF Loop Pattern with `break`

---

## 🎯 Learning Objectives

- Validate file stream opening handles safely.
- Read and display entire text documents character-by-character until EOF.
