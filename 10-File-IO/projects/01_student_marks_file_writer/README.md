# 🎓 Project 01: Student Marks File Writer

> Persist user input marks to a text file using formatted output `fprintf()`.

---

## 📌 Short Description

Ask the user to input marks for 3 subjects via `scanf`. Open a file `marks.txt` in `"w"` mode. Use `fprintf` to write the marks neatly into the file (e.g., `Subject 1: 85`). Cleanly close the file using `fclose()`.

---

## 📚 Topics Covered

- [x] User Input Reading (`scanf`)
- [x] Opening Files in Write Mode (`"w"`)
- [x] Formatted Text Writing (`fprintf`)
- [x] File Stream Closing (`fclose`)

---

## 🎯 Learning Objectives

- Move data from user input (RAM) to permanent disk storage (`marks.txt`).
- Apply `fprintf()` format specifiers to write clean structured text files.
