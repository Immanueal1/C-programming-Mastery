# 📖 Top 10 Technical Interview Theory Questions

> Core theoretical revision questions on Volatile RAM vs. Non-Volatile Disk Storage, File I/O Purpose, Text vs. Binary Files, File Pointer (`FILE *`), 3-Step File Workflow, File Access Modes (`"r"`, `"w"`, `"a"`), `NULL` Pointer Safety, `fgetc()` vs `fputc()` Data Direction, and the `EOF` Signal Macro.

---

### Question 1
**Volatile vs. Non-Volatile: Explain the difference between RAM and a Hard Disk. Why do normal C variables disappear when a program ends?**

---

### Question 2
**Why File I/O? What is the primary purpose of File I/O in software engineering? Give a real-world example of why persistent data is necessary.**

---

### Question 3
**Text vs. Binary: Conceptually, what is the difference between a text file (like `.txt`) and a binary file (like `.jpg`)?**

---

### Question 4
**The File Pointer: What is `FILE *` in C? Why do we need a pointer to communicate with a file?**

---

### Question 5
**The Golden Workflow: What are the three mandatory steps (Open ➜ Work ➜ Close) of handling files? Why is the last step so important?**

---

### Question 6
**File Modes: Contrast the behavior of `"w"` (Write) and `"a"` (Append) modes. What happens to existing data in both cases?**

---

### Question 7
**Missing Files: If you attempt to open a file that does not exist in `"r"` mode, what exactly does `fopen()` return? What happens if you do the same in `"w"` mode?**

---

### Question 8
**`NULL` Checking: Why is it considered a fatal programming error to perform an `fscanf()` or `fgetc()` without first checking if the file pointer is `NULL`?**

---

### Question 9
**`fgetc` vs `fputc`: Describe the direction of data flow for `fgetc()` and `fputc()`. Which one moves data from File to Program, and which moves Program to File?**

---

### Question 10
**The `EOF` Concept: What does `EOF` stand for? Is it an actual character visible in your text file, or is it a special signal generated by C's reading functions?**
