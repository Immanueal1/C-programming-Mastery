# 🚀 Project 03: NASA Rocket Countdown Simulation

> A real-time countdown simulator handling milestone messages and emergency abort signals.

---

## 📌 Short Description

Ask the user for a countdown time in seconds (e.g., 10). Use a `while` loop to print the countdown. If the countdown reaches 3, print "Ignition Sequence Start". At 0, print "Liftoff!". However, if the user inputs an abort code during an early prompt, break the sequence immediately using `break` and print "Launch Aborted".

---

## 📚 Topics Covered

- [x] Decrement Countdown `while` Loops
- [x] Condition Checking Inside Loop Iterations
- [x] Early Sequence Abort via `break`

---

## 🎯 Learning Objectives

- Control countdown iterations using `while` loops.
- Interrupt normal execution flow using emergency `break` conditions.
