# 🔢 Project 01: Custom Number Sequence Generator

> A flexible sequence generator that takes Start, End, and Step values to print count-up or count-down series safely.

---

## 📌 Short Description

Write a program that takes three inputs from the user: `Start`, `End`, and `Step`. Use a loop to print the sequence. If `Step` is positive, count up. If `Step` is negative, count down. Prevent infinite loops dynamically based on the inputs.

---

## 📚 Topics Covered

- [x] Dynamic `for` or `while` Loop Headers
- [x] Bi-Directional Updation (`i += Step`)
- [x] Infinite Loop Protection Guards

---

## 🎯 Learning Objectives

- Construct dynamic loop boundaries based on variable user inputs.
- Handle positive and negative step values to count up or down safely.
