# 🛠️ Chapter 4: Portfolio Mini Projects

> Practical, real-world mini projects built entirely using Chapter 4 concepts: `for`, `while`, `do-while` loops, `break`, `continue`, and character/integer iterators. No arrays, functions, or strings!

---

## 📌 Short Description

This folder contains 5 hands-on portfolio mini projects designed to apply loop iteration, bi-directional stepping, menu-driven `do-while` systems, rocket countdown sequences with abort breaks, multiplication grid formatting, and number filtering with `continue`.

---

## 📚 Topics Covered

- [x] Custom Sequence Generation with Dynamic Step Directions (`01_custom_number_sequence_generator`)
- [x] Menu-Driven Interactive Alphabet Engine (`02_the_english_alphabet_engine`)
- [x] Countdown Simulation with Ignition Traps & Abort Breaks (`03_nasa_rocket_countdown_simulation`)
- [x] Formatted Multiplication Table Grid Engine (`04_universal_multiplication_table_grid`)
- [x] Multiples Skipping Filter with `continue` (`05_the_banned_number_skipper`)

---

## 🎯 Learning Objectives

- Implement dynamic loop steppers capable of incrementing or decrementing safely based on user inputs.
- Construct interactive menu interfaces using `do-while` loops.
- Handle real-time user abort signals inside countdown `while` loops using `break`.
- Format multiplication grid outputs using width specifiers inside `for` loops.
- Filter out banned number multiples dynamically using `continue`.
