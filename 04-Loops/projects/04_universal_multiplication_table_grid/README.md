# ✖️ Project 04: Universal Multiplication Table Grid

> A mathematical grid printing application formatting multiplication tables up to $N \times 10$.

---

## 📌 Short Description

Ask the user for an integer N. Print the multiplication table for N from $N \times 1$ up to $N \times 10$. Format the output beautifully using `printf` so it looks like: `5 x 1 = 5`, `5 x 2 = 10`, etc.

---

## 📚 Topics Covered

- [x] Fixed-Range Iteration with `for` Loops
- [x] Multiplication Arithmetic inside Loops
- [x] Formatted Console Text Alignment

---

## 🎯 Learning Objectives

- Implement fixed-iteration `for` loops for mathematical table calculations.
- Format console output fields for aligned display.
