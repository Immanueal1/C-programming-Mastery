# 🚫 Project 05: The Banned Number Skipper

> A number sequence generator filtering out specific banned multiples dynamically using continue.

---

## 📌 Short Description

Prompt the user for a limit N and a "banned number" B. Count from 1 to N. If the current number is a multiple of B, use `continue` to skip printing it. Print all other numbers in a neat, comma-separated row.

---

## 📚 Topics Covered

- [x] Dynamic Range Iteration
- [x] Modulo Multiple Checking (`i % B == 0`)
- [x] Iteration Skipping via `continue`

---

## 🎯 Learning Objectives

- Filter specific numbers dynamically from an iteration sequence using `continue`.
- Prevent execution of trailing print statements when skip criteria are met.
