# 🔤 Project 02: The English Alphabet Engine

> A menu-driven character iteration application providing forward, reverse, and alternate alphabet printing.

---

## 📌 Short Description

Create a menu-driven program using a `do-while` loop. Option 1: Print A to Z. Option 2: Print Z to A. Option 3: Print alternate letters (A, C, E...). Option 0: Exit. Use `char` iterators exclusively for the logic.

---

## 📚 Topics Covered

- [x] Menu-Driven `do-while` Interface
- [x] Forward Character Iteration (`char ch = 'A'; ch <= 'Z'; ch++`)
- [x] Reverse Character Iteration (`char ch = 'Z'; ch >= 'A'; ch--`)
- [x] Alternate Character Stepping (`ch += 2`)

---

## 🎯 Learning Objectives

- Implement an interactive terminal menu using `do-while` loops.
- Manipulate `char` iterators using ASCII arithmetic.
