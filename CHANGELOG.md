## [1.0.0] - 2026-08-06

### ✨ Added
- Initial release of the **C-Programming-Mastery** open-source curriculum repository.
- Complete modular chapter layout covering Chapters 01 to 14.
- **Chapter 01 (Basics & Variables)**:
  - Unified theoretical guide (`README.md`).
  - Graduated practice directory with 30 starter problem files (`easy/`, `medium/`, `hard/`).
  - Dedicated interview module (`interview/`) containing `THEORY.md`, `OUTPUT_PREDICTION.md`, `DEBUGGING.md`, and `MCQs.md`.
  - Portfolio projects directory (`projects/`) containing 5 real-world application setups.
  - Visual cheat sheet notes (`images/`).
- Master PDF compilation of visual notes (`C programming Visual Notes_watermark.pdf`).
- Governance and repository infrastructure documentation:
  - Dual Licensing architecture (`LICENSE` with MIT for code & CC BY-NC-ND 4.0 for educational assets).
  - Code of Conduct (`CODE_OF_CONDUCT.md`).
  - Contribution guidelines (`CONTRIBUTING.md`).
  - Security policy (`SECURITY.md`).
  - Legal Notice & Copyright (`NOTICE`).
  - Citation specification (`CITATION.cff`).
  - Repository Roadmap (`ROADMAP.md`).
  - Student Learning Path (`LEARNING_PATH.md`).
  - Author Acknowledgements (`ACKNOWLEDGEMENTS.md`).
