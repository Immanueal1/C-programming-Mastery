# 🛠️ Chapter 3: Portfolio Mini Projects

> Practical, real-world mini projects built entirely using Chapter 3 concepts: `if-else`, `else-if` ladders, `switch-case` menus, logical operators, and relational logic. No loops or arrays!

---

## 📌 Short Description

This folder contains 5 hands-on portfolio mini projects designed to apply conditional branching, interactive menu selection, input validation, and guard clauses to realistic applications.

---

## 📚 Topics Covered

- [x] PIN Authentication & Multi-Option Account Management (`01_atm_menu_simulator`)
- [x] Subject Cutoff Validation & Academic Grading Ladders (`02_student_grade_management`)
- [x] Case Fall-Through Directive Systems (`03_traffic_signal_simulator`)
- [x] Complex University Admission Cutoff Logic (`04_admission_eligibility_system`)
- [x] Guard-Protected Terminal Arithmetic Calculators (`05_smart_terminal_calculator`)

---

## 🎯 Learning Objectives

- Implement multi-stage user authentication and transactional validation logic.
- Design interactive console menus using `switch-case` constructs.
- Construct complex logical expressions combining `&&` and `||` for admission criteria.
- Protect arithmetic operations against runtime crashes using guard clauses (`if (b == 0)`).
- Organize modular C project files inside individual subdirectories (`main.c`).
