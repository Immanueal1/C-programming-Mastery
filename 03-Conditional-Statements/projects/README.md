# 🛠️ Chapter 3 Portfolio Mini Projects

> Practical, real-world mini projects built entirely using Chapter 3 concepts: `if-else`, `else-if` ladders, `switch-case` menus, logical operators, and relational logic. No loops or arrays!

---

## 📌 Projects Overview

| Project Directory | Title | Core Objective |
| :--- | :--- | :--- |
| [`01_atm_menu_simulator/`](./01_atm_menu_simulator/) | ATM Menu Simulator | PIN authentication, `switch` menu (Balance, Withdraw, Deposit), and withdrawal validation. |
| [`02_student_grade_management/`](./02_student_grade_management/) | Student Grade Management | Subject pass/fail check (<35 cutoff), percentage calculation, and `else-if` grade ladder. |
| [`03_traffic_signal_simulator/`](./03_traffic_signal_simulator/) | Traffic Signal Simulator | Case fall-through handling (R/Y/G uppercase & lowercase) to trigger signal system directives. |
| [`04_admission_eligibility_system/`](./04_admission_eligibility_system/) | Admission Eligibility System | Complex Boolean criteria chaining (`&&`, `||`) for university admissions cutoff validation. |
| [`05_smart_terminal_calculator/`](./05_smart_terminal_calculator/) | Smart Terminal Calculator | Multi-operator `switch` calculator with nested `if-else` guards against division-by-zero crashes. |

---

## 🎯 Implementation Rules

- Do NOT use loop control structures (`for`, `while`, `do-while`) or arrays.
- Use conditional branching (`if`, `else if`, `else`, `switch`, `case`) exclusively.
- Ensure all source code resides in `main.c` within each project folder.
