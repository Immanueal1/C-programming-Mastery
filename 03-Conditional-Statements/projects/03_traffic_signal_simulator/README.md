# 🚦 Project 03: Traffic Signal Simulator

> An automated traffic signal directive controller utilizing character case fall-through and default error handling.

---

## 📌 Short Description

Read a single character input: 'R', 'Y', or 'G' (handle both uppercase and lowercase using switch case fall-through). Use a `switch` statement to print system directives ("STOP - Engine Off", "GET READY - Engine On", "GO - Maintain Speed Limit"). Use `default` to handle invalid inputs.

---

## 📚 Topics Covered

- [x] Character `switch` Selection Syntax
- [x] Case Stacking & Intentional Fall-Through (`case 'R': case 'r':`)
- [x] Unmatched Input Fallback via `default`
- [x] System Directive Terminal Formatting

---

## 🎯 Learning Objectives

- Group uppercase and lowercase input characters using case fall-through.
- Execute appropriate system commands based on sensor input.
- Safeguard against invalid inputs using `default` branch directives.
