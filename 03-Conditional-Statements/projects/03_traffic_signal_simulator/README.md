# 🚦 Project 03: Traffic Signal Simulator

## Description
Read a single character input: 'R', 'Y', or 'G' (handle both uppercase and lowercase using switch case fall-through). Use a `switch` statement to print system directives ("STOP - Engine Off", "GET READY - Engine On", "GO - Maintain Speed Limit"). Use `default` to handle invalid inputs.

## Concepts Used
- Character `switch` selection
- Intentional case fall-through (`case 'R': case 'r':`)
- `default` fallback handling
- Directives formatting
