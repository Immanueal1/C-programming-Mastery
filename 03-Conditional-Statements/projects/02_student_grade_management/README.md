# 🎓 Project 02: Student Grade Management (Tutor's Edition)

> An academic report card generator evaluating subject cutoff guards, percentage calculations, and letter grade ladders.

---

## 📌 Short Description

Read marks for Math, Physics, and Chemistry. Calculate the overall percentage. If the student fails any individual subject (`marks < 35`), print "Fail". If they pass all subjects, calculate their grade using an `else-if` ladder based on the overall percentage (A, B, C, D) and print a report card.

---

## 📚 Topics Covered

- [x] Pass/Fail Guard Clauses with Logical OR (`||`)
- [x] Cascading Grade Cutoff `else-if` Ladder
- [x] Overall Percentage Floating-Point Arithmetic
- [x] Formatted Terminal Report Card Output

---

## 🎯 Learning Objectives

- Apply early-exit guard clauses when individual passing criteria are unmet.
- Implement cascading `else-if` range checks for letter grade assignments.
- Calculate floating-point percentages from integer subject scores.
