# 🏧 Project 01: ATM Menu Simulator

> A console-based ATM banking interface evaluating PIN authentication, balance queries, withdrawal limit checks, and deposits.

---

## 📌 Short Description

Build a console application that hardcodes an account PIN (`1234`) and Balance (`₹10,000`). Prompt the user for a PIN. If correct, present a `switch` menu: 1. Check Balance, 2. Withdraw, 3. Deposit. Implement full withdrawal validation (multiples of 100, sufficient balance).

---

## 📚 Topics Covered

- [x] PIN Authentication via `if-else`
- [x] Interactive Terminal Menu using `switch`
- [x] Modulo Amount Validation (`amount % 100 == 0`)
- [x] Balance Boundary Checking & Error Guarding

---

## 🎯 Learning Objectives

- Authenticate user credentials before granting access to operations.
- Implement discrete option handling using `switch-case` branches.
- Prevent invalid financial transactions using multi-condition `if` checks.
- Maintain accurate variable state across user choices.
