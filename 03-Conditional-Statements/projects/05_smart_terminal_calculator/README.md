# 🧮 Project 05: Smart Terminal Calculator

> An interactive terminal calculator featuring division-by-zero runtime protection and modulo safeguards.

---

## 📌 Short Description

Build a highly functional calculator. Read an operator (`+`, `-`, `*`, `/`, `%`) and two integers. Use a `switch` statement to perform the calculation. Nest `if-else` blocks inside division and modulo cases to explicitly prevent division-by-zero crashes, printing a custom warning if the user attempts it.

---

## 📚 Topics Covered

- [x] Multi-Operator `switch` Branch Selection
- [x] Division-by-Zero Guard Clauses (`if (b == 0)`)
- [x] Nested `if-else` Blocks inside `switch` Cases
- [x] Integer Arithmetic & Modulo Operations

---

## 🎯 Learning Objectives

- Construct a multi-operation calculator engine using `switch(op)`.
- Protect mathematical operations against runtime divide-by-zero crashes.
- Combine `switch` selection with nested conditional checks cleanly.
