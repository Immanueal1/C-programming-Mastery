# 🧮 Project 05: Smart Terminal Calculator

## Description
Build a highly functional calculator. Read an operator (`+`, `-`, `*`, `/`, `%`) and two integers. Use a `switch` statement to perform the calculation. Nest `if-else` blocks inside division and modulo cases to explicitly prevent division-by-zero crashes, printing a custom warning if the user attempts it.

## Concepts Used
- Operator character `switch`
- Nested `if-else` guard clauses
- Division-by-zero runtime error prevention
- Integer & modulo arithmetic
