# 🏫 Project 04: Admission Eligibility System

> A university admissions screening application evaluating multi-criteria subject thresholds and alternative score pathways.

---

## 📌 Short Description

A university requires strict criteria: Math $\ge 65$, Physics $\ge 55$, Chemistry $\ge 50$, AND Total $\ge 190$. Alternatively, if Math + Physics alone is $\ge 140$, the student is also eligible. Create a program that reads the three marks and strictly uses complex `&&` and `||` logic to determine eligibility.

---

## 📚 Topics Covered

- [x] Compound Logical AND (`&&`) Chaining
- [x] Alternative Qualification Pathways using Logical OR (`||`)
- [x] Logical Operator Precedence & Parentheses Grouping
- [x] Clear Eligibility Decision Output

---

## 🎯 Learning Objectives

- Construct complex Boolean expressions for multi-variable qualification rules.
- Combine primary criteria and alternative conditions using `&&` and `||`.
- Enforce correct evaluation precedence using grouping parentheses.
