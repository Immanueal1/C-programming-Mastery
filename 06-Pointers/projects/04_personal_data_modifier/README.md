# 👤 Project 04: Personal Data Modifier

> A user profile updater modifying age (`int`), weight (`float`), and group grade (`char`) via multi-type pointer parameters.

---

## 📌 Short Description

Simulate updating a user profile in C. Create a function `updateProfile(int *a, float *w, char *g)`. Pass a user's age, weight, and group character addresses from `main()`. Increment age by 1, reduce weight by 2.5, and advance the group character to the next letter (e.g., `'A'` to `'B'`). Print the updated profile in `main()`.

---

## 📚 Topics Covered

- [x] Multi-Type Pointer Parameter Modifications (`int *`, `float *`, `char *`)
- [x] Dereference Increments & Character Advancement (`*g = *g + 1`)
- [x] Profile State Management in Memory

---

## 🎯 Learning Objectives

- Apply Call by Reference across diverse C primitive data types.
- Mutate user profile attributes directly in caller memory space.
