# 🔄 Project 02: Swap Two Numbers Using Pointers

> The classic C variable swapping program utilizing Call by Reference and pointer parameters.

---

## 📌 Short Description

Build a program containing the classic `swap(int *a, int *b)` function. Ask the user to input two integer values in `main()`, display them before swapping, pass their memory addresses to `swap()`, and print the swapped values in `main()`.

---

## 📚 Topics Covered

- [x] Call by Reference Function Parameters
- [x] Address Passing (`&x`, `&y`)
- [x] In-Place Variable Value Swapping using Temporary Variables

---

## 🎯 Learning Objectives

- Construct a reusable swap utility using pointer parameters.
- Verify that passing memory addresses allows a function to mutate caller variables.
