# 🧮 Project 05: The Root Finder (Quadratic Simulation)

> A mathematical root finder computing two values that sum and multiply to user-specified target totals using output pointer parameters.

---

## 📌 Short Description

Write a function `findRoots(int sum, int product, int *root1, int *root2)`. Using basic math/brute-force iteration over integers, find two numbers that add up to `sum` and multiply to `product`. Store the computed answers inside `root1` and `root2` pointers, and print them in `main()`.

---

## 📚 Topics Covered

- [x] Mathematical Problem Solving with Pointer Outputs
- [x] Returning Dual Output Roots via Pointers (`*root1`, `*root2`)
- [x] Search Loop Integration with Call by Reference

---

## 🎯 Learning Objectives

- Solve mathematical equations and output multiple solutions directly via pointers.
- Decouple mathematical searching logic from output presentation in `main()`.
