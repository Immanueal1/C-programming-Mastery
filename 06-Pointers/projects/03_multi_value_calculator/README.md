# 🔢 Project 03: Multi-Value Calculator

> An arithmetic engine returning four calculated values (sum, difference, product, division) from a single function call using output pointer parameters.

---

## 📌 Short Description

Create a function `doMath(int a, int b, int *sum, int *diff, int *prod, float *div)`. Prompt the user for two numbers in `main()`, pass them alongside the memory addresses of four output variables, and print the calculated results in `main()`. Handle division by zero safely.

---

## 📚 Topics Covered

- [x] Returning Multiple Calculated Results via Output Pointers
- [x] Mixed Data Type Pointer Parameters (`int *`, `float *`)
- [x] Division by Zero Safeguards

---

## 🎯 Learning Objectives

- Overcome C's single return value limitation using pointer parameters.
- Structure functions that update multiple caller variables simultaneously.
